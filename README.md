# ORFHEUSS

ORFHEUSS is a constitutional frame for AI: a layered architecture that separates generation, legitimacy, execution and audit.

This repository is the public preamble. It does not replace the technical runtime, application repositories, lesson programs or cultural archive. It defines how those parts should be read.

## Core thesis

```text
AI proposes.
Human disposes.
Audit remembers.
```

## What ORFHEUSS is

ORFHEUSS is not a chatbot prompt and not a generic AI wrapper. It is a governance-oriented architecture for making AI output legible, bounded and accountable.

It treats AI as a powerful black box, then places a constitutional layer around that box:

```text
Black box        = generative capacity
Codex            = rules and legitimacy
Ontology         = language and structure
Ethics           = boundary
Audit            = memory
Human authority  = final disposition
```

## Repository ordering principle

All related repositories should be classified before they are treated as active source material.

Canonical labels:

- `CANON` — public principles, language, identity and constitutional framing.
- `KERNEL` — executable governance logic, gates, invariants and audit logic.
- `APP` — user-facing application or prototype.
- `LESSON` — educational or transfer material.
- `ARCHIVE` — cultural, family or source archive.
- `ASSET` — attached files, generated material or supporting media.
- `EXPERIMENT` — unfinished proof of concept.
- `DEPRECATED` — retained for history only.

## Rule

Do not let AI learn from a pile. Let it read through law, layer and provenance.

More structure files will be added as the repositories are connected and cleaned.
